# Learno

Mobile Lern-Web-App für persönliche Fortschritte und gemeinsame Prüfungstermine. Python, SQLite, WSGI und JavaScript ohne Frontend-Buildschritt; der Anwendungscode liegt in [`learno/`](learno/).

- [Start, Funktionen und Datenerhaltung](learno/README.md)
- [Leitfaden für das Code-Review](learno/REVIEW.md)
- [Testabdeckung und Prüfungsgrenzen](learno/TEST_REPORT.md)
- [Sichere Bereitstellung mit Backups](learno/ONLINE_START.md)

Für das Review eine eigene lokale Installation verwenden. Echte Nutzerdatenbanken, Uploads, Backups, Zugangsdaten und lokale Betriebsprotokolle sind nicht Bestandteil dieses Repositorys.
